# Research sources

The repository includes a copy of the 2024 thesis at [`docs/assets/publications/Ferdinand_O_Schnell_BA.pdf`](../docs/assets/publications/Ferdinand_O_Schnell_BA.pdf). The related journal article is listed by DOI in the [research guide](../docs/research.md). Figure source pages, crop coordinates, attribution, and asset provenance are recorded in [`docs/assets/research/manifest.json`](../docs/assets/research/manifest.json).

To repeat figure extraction, place source PDFs in the ignored `references/local/` directory and run `python3 tools/extract_figures.py`. See [`demo/notes.md`](../demo/notes.md) for source filenames and extraction dependencies.
